# 💼  Job Portal Web Application

A modern job portal platform designed to connect job seekers with employers in a simple, efficient, and scalable way.  
The platform allows users to search for jobs, apply online, and track application status, while employers can post and manage job listings.

---

## 🚀 Tech Stack

### 🔧 Backend
- Java (Spring Boot)
- Spring Data JPA
- Spring Security (JWT - upcoming)
- MySQL

### 💻 Frontend
- React.js
- Axios
- React Router

### 🛠️ Tools
- Git & GitHub
- Postman (API testing)
- Swagger (API documentation - upcoming)

## ✨ Features

### 👤 User Management
- User registration (Job Seeker / Employer)
- Authentication (JWT - in progress)
- Role-based access control

### 💼 Job Management
- Employers can create, update, and delete job posts
- Job seekers can browse available jobs

### 📄 Job Application
- Apply to jobs directly
- Track application status:
    - Applied
    - Shortlisted
    - Rejected
    - Hired

### 🔍 Search & Filtering (Planned)
- Search by title, location, skills
- Filter by category and salary

### 🛡️ Admin Dashboard (Planned)
- Manage users
- Approve employers
- Monitor platform activity
